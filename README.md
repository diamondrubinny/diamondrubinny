## 🧭 How I build

- 🔐 **Security by design** — least privilege, server-side validation, no secrets in code
- ♿ **Accessibility first** — WCAG 2.1 AA as a baseline, keyboard &amp; screen-reader friendly
- 🇮🇱 **Hebrew / RTL native** — every product works right-to-left out of the box
- 🏠 **Self-hosted &amp; privacy-respecting** — your data stays on your server
