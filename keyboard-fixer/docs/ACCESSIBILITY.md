# הצהרת נגישות – KeyFlip

> **טיוטה לבדיקה מקצועית (יועץ נגישות) לפני פרסום סופי.** אין בה הצהרת ציות מלא.

עודכן לאחרונה: [תאריך]

## מחויבות
אנו שואפים שממשקי KeyFlip יהיו שמישים ככל הניתן לכל אדם, כולל אנשים עם מוגבלויות.

## היעד
התאמה ל-WCAG 2.1 ברמה AA ולת"י 5568 (דורש בדיקה מקצועית לאימות).

## התאמות שבוצעו
- דפי התוסף (חלון התוסף ודף ההגדרות): HTML סמנטי, `lang="he"` ו-`dir="rtl"`, תוויות לכל שדה, ניווט מלא במקלדת, סימון פוקוס נראה, מצב כהה/בהיר לפי המערכת, כיבוד `prefers-reduced-motion`, הודעות מצב מוקראות (`aria-live`).
- ניגודיות צבעים שנבדקה אוטומטית (axe-core, WCAG 2.1 A/AA) בשני מצבי תצוגה: ללא ממצאים.
- הודעות התוסף בדף (במקרה שאין שדה פעיל) מוקראות כ-`role="status"`.
- תפריט המגש בתוכנת Windows הוא תפריט מערכת סטנדרטי ונגיש לקוראי מסך; מוגדר RTL.

## מגבלות ידועות
- טרם בוצעה בדיקה ידנית עם קורא מסך (NVDA/JAWS) ובדיקת זום 200%.
- תיקון אוטומטי משנה טקסט בזמן הקלדה; משתמשי קורא מסך עשויים לשמוע את המילה המתוקנת רק אחרי הרווח. ניתן לכבות את התיקון האוטומטי בהגדרות ולהשתמש בהמרה ידנית.
- הודעות בלון של תוכנת Windows תלויות בהגדרות ההתראות של המערכת.
