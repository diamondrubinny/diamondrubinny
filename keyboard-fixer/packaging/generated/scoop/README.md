# scoop-keyflip

Scoop bucket for [KeyFlip](https://github.com/diamondrubinny/diamondrubinny) – fixes text typed in the wrong keyboard layout (Hebrew/English).

```powershell
scoop bucket add keyflip https://github.com/diamondrubinny/scoop-keyflip
scoop install keyflip
```

The app is currently not code-signed, so Windows SmartScreen or antivirus software may warn about it.
Review the source and the published SHA-256 before installing. Manifest version: 0.1.0.15.
