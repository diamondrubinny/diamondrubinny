# KeyFlip – סרטון פרסום (9:16, 30 שניות)

הקובץ המוכן: `out/keyflip-promo-9x16.mp4` (1080×1920, 30fps, אפקטי קול ומוזיקה, **ללא קריינות**).
מתאים ל-TikTok, YouTube Shorts ו-Instagram Reels.

## תסריט קריינות (בעברית, מתוזמן לוידאו)
| שניות | טקסט |
|---|---|
| 0.0–3.2 | כתבתם משפט שלם... ורק אז שמתם לב שהמקלדת באנגלית? |
| 3.2–7.0 | הכול יצא ג׳יבריש, ואתם צריכים למחוק ולהקליד הכול מחדש. |
| 7.0–11.5 | תכירו את KeyFlip, כלי חינמי שמתקן את זה בשבריר שנייה. |
| 11.5–16.0 | פשוט ממשיכים להקליד. בסוף כל מילה הוא מזהה את הטעות... ומתקן לבד. |
| 16.0–20.5 | וזה עובד גם הפוך: עברית באנגלית, ואנגלית בעברית. |
| 20.5–25.0 | הכול רץ אצלכם במחשב, בלי לשלוח מידע, והוא לא נוגע בשדות סיסמה. |
| 25.0–30.0 | תוסף לכרום ותוכנה לווינדוס, בקוד פתוח ובחינם. הקישור בתיאור! |

קצב דיבור מומלץ: מהיר-נעים, כ-2.3 מילים לשנייה. הכתוביות כבר צרובות בוידאו; `narration.srt` מיועד להעלאה כקובץ כתוביות/לעריכה.

## איך מוסיפים קריינות
1. **קול אנושי (מומלץ):** מקליטים את הטקסט בטלפון לפי התזמון, ושומרים כ-`voice.mp3`/`voice.wav`.
2. **קול סינתטי:** כל שירות המפיק עברית (למשל Azure/Google/ElevenLabs – לבדוק זמינות עברית ותנאי רישיון). אם משתמשים בקול סינתטי, יש לסמן זאת לפי כללי הפלטפורמה (דורש אימות מול כללי TikTok/YouTube).
3. ממזגים:
```bash
./add_voice.sh voice.mp3          # יוצר out/keyflip-promo-9x16-voice.mp4
```

## פרסום
**כותרת (YouTube Shorts / TikTok):** כתבתם באנגלית במקום בעברית? KeyFlip מתקן לבד
**תיאור:**
כתבתם משפט שלם ואז גיליתם שהמקלדת הייתה בשפה הלא נכונה? KeyFlip מתקן את זה אוטומטית, עברית↔אנגלית.
✓ תוסף לכרום + תוכנה לווינדוס ✓ בחינם ובקוד פתוח ✓ הכול רץ אצלכם, בלי שליחת מידע ✓ לא נוגע בשדות סיסמה
הורדה: [קישור – https://github.com/diamondrubinny/diamondrubinny/releases, או הריפו keyflip כשיהיה]
הערה: גרסת תצוגה מקדימה. Windows עלולה להציג אזהרה כי הקובץ עדיין לא חתום.
**האשטגים:** #עברית #טיפים #טכנולוגיה #כרום #ווינדוס #קודפתוח #KeyFlip #פרודוקטיביות

## מידע שחשוב לא להוסיף לפרסום
אין להבטיח "100% דיוק". דיוק הזיהוי בבדיקות שלנו כ-96–97% (ראו README).
